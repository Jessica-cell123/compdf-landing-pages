전체 플랫폼 범위

당신의 플랫폼을 선택하세요

각 플랫폼 SDK에는 전체 편집기 · 변환 · 생성 기능 세트가 포함되어 있습니다

🌐

Web SDK

JavaScript/TypeScript는 React/Vue/Angular를 지원하며 브라우저 측에서 완전한 PDF 보기, 편집 및 생성 기능을 갖추고 있습니다.

세부정보 보기 →문서 →
☁️

Server SDK

Java/.NET 서버측 PDF 라이브러리는 Spring Boot 및 .NET Core 백엔드에 적합하며 변환, 생성, 추출과 같은 일괄 처리 기능을 제공합니다.

Java SDK → .NET SDK →
📱

Mobile SDK

기본 Android/iOS, Flutter, React Native, 단일 코드 세트 또는 여러 플랫폼용 기본으로 모바일 측의 모든 PDF 요구 사항을 충족합니다.

Android → iOS → Flutter → React Native →
🖥️

Desktop SDK

Windows(WinForms/WPF) 및 macOS(AppKit/Mac Catalyst) 기본 SDK, 데스크탑에서 전문적인 PDF 편집 및 변환.

Windows → macOS →
