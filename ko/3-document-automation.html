RAG 시나리오 문제점

지식 기반 효과가 좋지 않습니까? 문제는 종종 문서 구문 분석 프로세스에 있습니다

RAG 시스템의 답변 품질은 기본 문서 구문 분석의 정확성과 구조 유지 능력에 따라 달라집니다

📊

테이블 정보 손실

일반 OCR은 복잡한 테이블의 행-열 관계를 유지할 수 없으며 병합된 셀과 크로스 페이지 테이블이 거의 완전히 손상되었습니다

🧩

혼란스러운 레이아웃 구조

여러 열, 혼합된 그래픽과 텍스트, 사이드바 등의 복잡한 레이아웃이 잘못 연결되어 원래 의미 논리를 파괴함

✂️

낮은 분할 품질

구조적 정보 부족으로 인한 청크 부적절한 분할 세분성으로 인해 핵심 컨텍스트가 잘리거나 중복됨

❌

RAG가 잘못된 질문에 답합니다

기본 구문 분석 품질이 부족하고 벡터 검색의 재현율이 낮으며 LLM이 잘못된 컨텍스트를 기반으로 환각을 생성합니다

핵심 구문 분석 기능

ComPDF AI는 RAG 시나리오에 무엇을 제공합니까?

자체 개발한 PDF 파싱 코어 + AI 딥러닝 모델을 기반으로 일반 OCR을 훨씬 능가하는 문서 이해 능력 제공

📐

PDF 기본 구문 분석 엔진

PDF의 기본 텍스트 흐름, 글꼴 정보 및 좌표 위치를 직접 읽고 OCR 없이 디지털 PDF의 텍스트와 구조를 정확하게 복원하며 원래 조판의 의미 수준을 유지합니다.

  • 텍스트 스트림을 직접 추출합니다. OCR 오류는 없습니다
  • 글꼴, 글꼴 크기, 색상 등과 같은 형식 정보를 보존합니다.
  • 제목 수준 및 단락 관계를 정확하게 복원
  • PDF 내장 북마크 및 디렉토리 구조 지원
🧠

AI 기반 레이아웃 분석

딥러닝 기반 레이아웃 감지 모델은 10개 이상의 레이아웃 요소(제목, 텍스트, 표, 그림, 머리글, 바닥글, 각주 등)를 식별하고 문서의 논리적 읽기 순서를 정확하게 나눌 수 있습니다.

  • 여러 열, 혼합 그래픽 및 텍스트 자동 분할
  • 제목과 텍스트 수준의 자동 연결
  • 머리글과 바닥글, 워터마크 자동 필터링
  • 페이지 간 단락 및 표 자동 연결
📊

복잡한 테이블 구조 추출

특수 테이블 감지 및 셀 인식 모델을 채택하여 병합된 셀, 중첩 테이블, 프레임 없는 테이블의 행-열 관계를 정확하게 복원하고 구조화된 테이블 데이터를 출력합니다.

  • 셀을 병합하여 행 및 열 매핑을 정확하게 복원
  • 프레임이 없는/점선 프레임 테이블 인식
  • 자동 교차 페이지 테이블 접합 및 연속 테이블 인식
  • HTML/Markdown/JSON으로 테이블 데이터 출력
🔤

스캔된 OCR + 레이아웃 복원

이미지 PDF 및 스캔 문서의 경우 고정밀 OCR 텍스트 인식을 먼저 수행한 후 레이아웃 분석을 통해 문서 구조를 복원하므로 디지털 PDF와 동일한 파싱 품질을 얻을 수 있습니다.

  • 필기와 인쇄의 혼합 인식
  • 프로세스 완료

ComPDF AI가 RAG 전처리에 더 적합한 이유는 무엇입니까?

이중 엔진 아키텍처

⚡

디지털 PDF는 네이티브 엔진으로 직접 추출하고, 스캔한 문서는 AI OCR + 레이아웃 분석으로 추출합니다. 두 경로 모두 고품질의 구조화된 데이터를 출력합니다

구조 인식 세분화

🎯

레이아웃 분석 결과를 바탕으로 Semantic 레벨의 Chunk Segmentation을 수행하고, 제목 레벨, 문단 경계, 표 범위 등을 기준으로 자동 분할하여 Hard truncation 방지

테이블별 최적화

📊

특별히 훈련된 테이블 감지 및 셀 인식 모델, 재무 보고서 테이블 및 다층 헤더와 같은 복잡한 시나리오에 대한 타겟 최적화

프레임워크는 플러그 앤 플레이 방식입니다

🔌

출력 마크다운은 2차 변환 없이 LangChain, LlamaIndex, Dify, FastGPT 등과 같은 주류 프레임워크에서 직접 사용할 수 있습니다

20개 이상의 형식 적용

📄

PDF 외에도 Word, PPT, Excel, 그림 등 20여 가지 형식의 통합 파싱을 지원하여 모든 문서 유형을 하나의 API로 처리
