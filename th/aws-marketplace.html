ComPDF × AWS Marketplace

บน AWSการปรับใช้ ComPDF เพียงคลิกเดียว

ComPDF พร้อมใช้งานบน AWS Marketplace ในรูปแบบอิมเมจ AMI เปิดใช้อินสแตนซ์บน EC2 เพื่อรับความสามารถในการแปลง PDF ที่สมบูรณ์ - การเรียกเก็บเงิน AWS แบบรวม การปรับใช้เครือข่ายส่วนตัว ข้อมูลไม่ออกจาก VPC และโครงสร้างพื้นฐานการประมวลผลเอกสารระดับองค์กรจะพร้อมใช้งานในไม่กี่นาที

ข้อได้เปรียบหลัก

เหตุใดจึงเลือก AWS Marketplace เพื่อปรับใช้ ComPDF

🚀

ปรับใช้เพียงคลิกเดียว ออนไลน์ได้ในไม่กี่นาที

หลังจากสมัครรับอิมเมจ AMI จาก AWS Marketplace คุณสามารถเริ่ม EC2 instance เพื่อรับบริการประมวลผลเอกสาร ComPDF ที่สมบูรณ์โดยไม่ต้องตั้งค่าสภาพแวดล้อมด้วยตนเอง

💰

การเรียกเก็บเงิน AWS แบบรวม

ค่าธรรมเนียมการสมัครจะรวมอยู่ในใบเรียกเก็บเงินรายเดือนของ AWS ซึ่งสนับสนุนการหักเงินจากโปรแกรมส่วนลดสำหรับองค์กร ทำให้การจัดซื้อจัดจ้างขององค์กรและกระบวนการกระทบยอดทางการเงินง่ายขึ้น

🔒

ข้อมูลไม่สามารถส่งออกจาก VPC

ปรับใช้ในเครือข่ายส่วนตัว VPC ของตัวเอง คำขอประมวลผลเอกสารจะถูกส่งผ่านอินทราเน็ต และข้อมูลไม่ผ่านเครือข่ายสาธารณะ ซึ่งเป็นไปตามข้อกำหนดการปฏิบัติตามข้อกำหนดของอุตสาหกรรมการเงิน การแพทย์ และอุตสาหกรรมอื่นๆ

📈

การขยายตัวและการหดตัวที่ยืดหยุ่น

ตามความสามารถที่ยืดหยุ่นของ EC2 สามารถปรับข้อมูลจำเพาะของอินสแตนซ์ได้ตลอดเวลาตามปริมาณการประมวลผลเอกสาร ขยายโดยอัตโนมัติระหว่างโหลดสูง และลดต้นทุนเมื่อไม่ได้ใช้งาน

ความสามารถหลัก

ความสามารถในการประมวลผลเอกสารที่ AMI มอบให้

ครอบคลุมสถานการณ์การแปลง PDF ทั้งหมดและเข้าถึงได้ง่ายผ่าน HTTP API

🔄

การแปลงรูปแบบ PDF

PDF ↔ Word / Excel / PPT / HTML / รูปภาพ การแปลงแบบสองทาง คงรูปแบบเดิมไว้

📄

สำนักงานเป็น PDF

แปลงเอกสาร Word, Excel และ PPT เป็น PDF เป็นกลุ่ม เหมาะสำหรับการเก็บถาวรและการแจกจ่ายแบบรวมศูนย์

🖼️

การแปลงรูปภาพ

รองรับการแปลงระหว่าง JPG, PNG, TIFF, BMP และรูปแบบรูปภาพทั่วไปอื่น ๆ และ PDF

📐

การแปลงรูปแบบ PDF

แปลง PDF/A, PDF/X, PDF/E และรูปแบบมาตรฐานอื่นๆ เพื่อตอบสนองความต้องการในการเก็บถาวรและการพิมพ์

⚡

การประมวลผลเป็นชุด

รองรับการประมวลผลเอกสารเป็นชุดพร้อมกันสูงและการปรับสมดุลโหลดอัตโนมัติ เหมาะสำหรับสภาพแวดล้อมการผลิตขนาดใหญ่

🔗

RESTful API

อินเทอร์เฟซ HTTP API มาตรฐานสามารถเรียกใช้ในภาษาใดก็ได้และสามารถรวมเข้ากับระบบที่มีอยู่ได้อย่างง่ายดาย
