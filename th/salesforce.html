การบูรณาการ ComPDF × Salesforce

ทำงานกับ PDF ได้โดยตรงใน Salesforce
ไม่ต้องออกไม่ต้องกระโดด

ComPDF Web SDK ถูกฝังอยู่ใน Salesforce ในรูปแบบ Lightning Web Component ช่วยให้ทีมขาย กฎหมาย และฝ่ายปฏิบัติการสามารถดู แก้ไข ใส่คำอธิบายประกอบ ลงนาม และกรอกแบบฟอร์มได้โดยตรงภายในอินเทอร์เฟซของ Salesforce ข้อมูลจะไม่ออกจาก Salesforce และเวิร์กโฟลว์จะไม่ถูกขัดจังหวะ

เหตุใดจึงเลือก ComPDF ใน Salesforce

🔗

ฝังอยู่ใน Salesforce ได้อย่างราบรื่น

ฝังหน้าบันทึกของ Salesforce ป๊อปอัพ Flow และไซต์คลาวด์ประสบการณ์เป็น Lightning Web Components ช่วยให้ผู้ใช้สามารถทำงานกับเอกสาร PDF ทั้งหมดโดยไม่ต้องออกจากสภาพแวดล้อมของ Salesforce

🔒

การปฏิบัติตามข้อกำหนดด้านความปลอดภัยของข้อมูล

โหลดไฟล์โดยตรงจาก ContentVersion, เอกสารแนบ หรือ S3 ภายนอกของ Salesforce โดยสืบทอดระบบสิทธิ์ของ Salesforce โดยสมบูรณ์ และข้อมูลจะไม่ผ่านเซิร์ฟเวอร์ของบุคคลที่สาม

🎨

การปรับแต่ง UI ที่ยืดหยุ่น

แถบเครื่องมือ ปุ่ม และพฤติกรรมเชิงโต้ตอบทั้งหมดสามารถปรับแต่งได้ตามข้อกำหนดแบรนด์ Salesforce ของบริษัทและกระบวนการทางธุรกิจ เพื่อให้ตรงกับประสบการณ์ผู้ใช้ที่เป็นหนึ่งเดียว

⚡

บูรณาการอย่างรวดเร็ว

การให้โค้ดตัวอย่าง LWC + Apex ที่พร้อมใช้งานทันที ช่วยให้นักพัฒนาสามารถปรับใช้การผสานรวมให้เสร็จสิ้นได้ภายในไม่กี่ชั่วโมงโดยไม่ต้องเริ่มต้นใหม่ทั้งหมด

ฟังก์ชั่นหลัก

คุณสามารถทำอะไรได้บ้างใน Salesforce

ฟังก์ชันการทำงานเต็มรูปแบบของ ComPDF Web SDK มีอยู่ใน Salesforce

👁️

มุมมอง PDF

เอ็นจิ้นการเรนเดอร์ประสิทธิภาพสูงรองรับการเปิดไฟล์ขนาดใหญ่ในไม่กี่วินาที การเปลี่ยนหน้าและซูมได้อย่างราบรื่น

✏️

การแก้ไขเอกสาร

ข้อความ รูปภาพ และลายน้ำสามารถแก้ไขได้โดยตรง โดยไม่เปลี่ยนแปลงเค้าโครงดั้งเดิม

📝

คำอธิบายประกอบ คำอธิบายประกอบ

เครื่องมือคำอธิบายประกอบมากกว่า 20 รายการ เช่น การเน้น การขีดเส้นใต้ รูปร่าง สติ๊กเกอร์ ฯลฯ รองรับการทำงานร่วมกันหลายคน

📋

การกรอกแบบฟอร์ม

การจดจำการควบคุมแบบฟอร์มแบบโต้ตอบโดยอัตโนมัติ รองรับการตรวจสอบข้อมูลและการกรอกอัตโนมัติ

✍️

ลายเซ็นอิเล็กทรอนิกส์

ลงนามในสัญญาได้โดยตรงภายใน Salesforce โดยไม่ต้องใช้เครื่องมือลงนามจากบุคคลที่สาม

🔐

ความปลอดภัยและการส่งออก

การเข้ารหัส PDF การควบคุมสิทธิ์ การประมวลผลข้อความไซเฟอร์ และการบันทึกกลับไปยัง Salesforce หลังจากการประมวลผล

บูรณาการอย่างรวดเร็ว

บูรณาการเสร็จสิ้นภายในไม่กี่ชั่วโมง

นำเสนอส่วนประกอบ LWC ที่สมบูรณ์ + ตัวอย่างโค้ด Apex พร้อมใช้งานทันทีตั้งแต่แกะกล่อง

// Install via npm $ npm install @compdf/web-sdk // Import LWC component import { LightningElement, track } from 'lwc'; import PDFViewer from '@compdf/salesforce-lwc'; // Open PDF from Salesforce ContentVersion const viewer = new PDFViewer(); viewer.loadFromSalesforce(contentVersionId);
