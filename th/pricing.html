FAQ

คำถามที่พบบ่อย

ComPDF SDK มีราคาเท่าใด▼
SDK ได้รับอนุญาตเป็นรายปี และราคาจะพิจารณาจากแพลตฟอร์มที่เลือก (เว็บ/มือถือ/เดสก์ท็อป/เซิร์ฟเวอร์) และการรวมฟังก์ชัน เริ่มต้นขั้นต่ำที่ 1,300 ดอลลาร์สหรัฐฯ ต่อปี ปริมาณการประมวลผลเอกสารไม่จำกัด และไม่จำกัดจำนวนผู้ใช้งาน
SDK รองรับแพลตฟอร์มใดบ้าง▼
รองรับ 9 แพลตฟอร์มหลัก รวมถึงเว็บ (JavaScript), iOS, Android, Flutter, React Native, Windows, macOS, Java และ .NET
ฉันสามารถทดลองใช้ผลิตภัณฑ์ก่อนซื้อสิทธิ์การใช้งานได้หรือไม่▼
ใช่ ลงทะเบียน ComPDF Portal แล้วคุณจะได้รับคีย์ทดลองใช้งานฟรี 30 วันสำหรับทุกแพลตฟอร์ม เพื่อทดสอบในสภาพแวดล้อมการทำงานจริงของคุณโดยไม่มีลายน้ำ และยังได้รับผลิตภัณฑ์ที่ทำงานได้อย่างสมบูรณ์พร้อมไฟล์และผู้ใช้ไม่จำกัด ขอรับคีย์ทดลองใช้งานฟรีได้แล้ววันนี้
มีให้ทดลองใช้ฟรีหรือไม่?▼
คุณสามารถลงทะเบียน ComPDF Portal และรับไฟล์ฟรี 200 ไฟล์สำหรับโปรแกรมแก้ไขและแปลง PDF, 20 หน้าฟรีสำหรับการแยกวิเคราะห์เอกสาร AI, 20 หน้าฟรีสำหรับการแยกเอกสาร AI ต่อเดือน คุณสามารถใช้บัญชีสำหรับการพัฒนาหรือการทดสอบได้ อ่านข้อมูลอ้างอิง API ของเราและเริ่มต้นใช้งานได้เลย
API รองรับฟีเจอร์อะไรบ้าง?▼
รองรับการแปลง PDF (Office/รูปภาพ/HTML), การแก้ไข PDF (รวม/แยก/หมุน), การจดจำ OCR, การเพิ่มลายน้ำ, การบีบอัด, การแยกวิเคราะห์และแยกเอกสาร AI ฯลฯ
รองรับการใช้งานส่วนตัวหรือไม่?▼
สนับสนุน. SDK รองรับการปรับใช้ส่วนตัว และ API ยังมีโซลูชันที่โฮสต์ด้วยตนเองอีกด้วย ข้อมูลถูกปรับใช้บนเซิร์ฟเวอร์ของตัวเองและไม่ออกจากอินทราเน็ตขององค์กร
มีส่วนลดสำหรับองค์กรหรือไม่▼
จัดหา. ลูกค้าที่ซื้อสินค้าจำนวนมากต่อปีจะได้รับส่วนลดตามปริมาณและสนับสนุนรูปแบบการอนุญาตของ OEM โปรดติดต่อทีมขายเพื่อขอใบเสนอราคาที่กำหนดเอง
SDK และ API สามารถใช้พร้อมกันได้หรือไม่▼
สามารถ. ลูกค้าจำนวนมากใช้ทั้ง SDK (สำหรับการดู/การแก้ไขฝั่งไคลเอ็นต์) และ API (สำหรับการประมวลผลแบทช์ฝั่งเซิร์ฟเวอร์) ซึ่งเสริมซึ่งกันและกัน
