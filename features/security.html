核心能力

Security 核心功能

Security 模块为企业文档安全保驾护航，从传输加密到访问控制，多层防护机制确保敏感文档不被未授权访问。

🔐

密码加密

支持 AES 128 位和 256 位加密算法，设置文档打开密码和权限密码双重保护

🚫

权限控制

细粒度权限设置：禁止打印、禁止复制内容、禁止编辑、禁止添加注释等独立控制

🔑

证书加密

基于 X.509 数字证书的公钥加密，确保只有持有合法证书的用户才能解密查看

🛡️

审计追踪

文档操作全流程审计日志记录，追踪每次打开、编辑、打印、签名操作
