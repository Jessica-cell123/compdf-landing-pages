FAQ

常见问题

ComPDF SDK 如何定价？▼
SDK 按年授权，价格根据所选平台（Web / 移动端 / 桌面端 / 服务端）和功能组合确定，最低 $1,300/年起。不限文档处理量和不限用户数。
SDK 支持哪些平台？▼
支持 Web（JavaScript）、iOS、Android、Flutter、React Native、Windows、macOS、Java、.NET 共 9 大平台。
如何获取 SDK 试用？▼
注册 ComPDF 会员即可申请 30 天全功能免费试用 License，无需信用卡。试用期间可体验所有功能和平台。
Cloud API 的文档量如何计算？▼
每次 API 调用处理一页文档计为一份。免费层每月 200 份，Growth 层 5,000 份，Pro 层 10,000 份。超过部分可购买附加包或升级方案。
API 支持哪些功能？▼
支持 PDF 转换（Office/图片/HTML）、PDF 编辑（合并/拆分/旋转）、OCR 识别、水印添加、压缩、AI 文档解析与抽取等。
是否支持私有化部署？▼
支持。SDK 支持私有化部署，API 也提供 Self-hosted 方案。数据部署在自有服务器，不出企业内网。
是否提供企业折扣？▼
提供。年采购量大的客户可享受批量折扣，支持 OEM 授权模式。请联系销售团队获取定制报价。
SDK 和 API 可以同时使用吗？▼
可以。许多客户同时使用 SDK（用于客户端查看/编辑）和 API（用于服务端批量处理），两者互补。
