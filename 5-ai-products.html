产品 1

ComPDF AI
智能文档处理引擎

ComPDF AI 是核心的智能文档处理产品，提供智能文档解析与智能文档抽取两大核心能力，可从各类文档中自动提取结构化数据。
  • 📤智能文档抽取 — 自动识别并提取文档中的关键字段（金额、日期、供应商等）
  • 📄智能文档解析 — 深度解析文档版面、表格、段落，输出结构化数据
  • 🌐多语言支持 — 覆盖中、英、日、韩等多种语言文档
  • 📊多格式输出 — 支持 JSON、CSV、Markdown 等结构化输出
  • 🔗API 集成 — 通过 REST API 与企业系统无缝对接
🤖

核心能力

智能文档解析 智能文档抽取 表格识别 版面分析 OCR 识别 多语言
产品 2

AI 助手
对话式文档处理

AI 助手嵌入 Web Demo 中，支持通过自然语言对话实现文档自动化处理。用户可以通过问答方式完成批量注释、内容编辑、密文标记等操作。
  • 💬实时问答 — 针对文档内容进行实时对话与信息查询
  • 📝批量注释 — 通过对话指令批量添加注释、高亮、标记
  • ✏️内容编辑 — 以自然语言指示 AI 完成文本修改与格式调整
  • 🔒密文标记 — 自动识别敏感信息并进行涂黑/脱敏处理
  • 🌐Web Demo 嵌入 — 直接集成在 Web 端，即开即用
💬

对话式操作

用户：把第 3 页所有金额数字高亮标注
AI 助手：已完成，共标注 12 处金额数字 ✓
用户：将文档中所有身份证号做密文处理
AI 助手：已识别 5 处身份证号并完成涂黑 ✓

AI Skills
全功能 PDF 处理技能

AI Skills 上线了所有 ComPDF API 支持的功能，包括编辑、转换、提取、生成等 30+ 种 PDF 处理能力，可直接被 AI Agent 调用执行。
  • ✏️编辑类 Skills — 文本编辑、注释添加、合并、分割、页面管理
  • 🔄转换类 Skills — PDF ⇄ Word / Excel / PPT / HTML / 图片
  • 📤提取类 Skills — 文本提取、表格识别、图片提取、KVP 提取
  • 📄生成类 Skills — 模板填充、报告生成、水印添加、批量输出
  • 🧩Agent 友好 — 可被 Claude / GPT 等 AI Agent 直接调用

产品 4

MCP Server
标准化 AI 协议接入

MCP Server 基于 Model Context Protocol 标准协议，上线了智能文档处理相关功能，让各类 AI 框架和 Agent 能够通过统一协议调用 ComPDF 的文档处理能力。
  • 🔌标准协议 — 基于 MCP 标准，跨平台通用接入
  • 🤖智能文档处理 — 聚焦文档解析、抽取等 AI 处理能力
  • 🔗多框架支持 — 兼容 Claude、LangChain、AutoGen 等 AI 框架
  • ⚙️自适应接口 — AI Agent 可根据任务自动选择合适的处理方法
  • 🛡️安全可控 — 支持认证鉴权、用量控制、数据隔离
