ComPDF × Salesforce 集成

Salesforce 内で直接 PDF を処理
離脱不要、遷移不要

ComPDF Web SDK は Lightning Web Component として Salesforce に埋め込まれ、営業、法務、運用チームが Salesforce 画面内で直接 PDF の表示、編集、注釈、署名、フォーム入力を完了できます。データは Salesforce から出ることなく、ワークフローは中断しません。

統合の優位性

为什么在 Salesforce 中选择 ComPDF

🔗

シームレスに埋め込み Salesforce

Lightning Web Component として Salesforce のレコードページ、Flow ポップアップ、Experience Cloud サイトに埋め込み、ユーザーは Salesforce 環境を離れることなくすべての PDF 文書を処理できます。

🔒

データセキュリティとコンプライアンス

Salesforce の ContentVersion、Attachment、または外部 S3 から直接ファイルをロード。Salesforce の権限体系を完全継承し、データはサードパーティサーバーを経由しません。

🎨

UI の柔軟なカスタマイズ

ツールバー、ボタン、インタラクション動作は企業の Salesforce ブランドガイドラインと業務フローに応じてカスタマイズ可能。統一されたユーザー体験を実現。

⚡

迅速な統合

即時使用可能な LWC + Apex サンプルコードを提供。開発者は数時間で統合デプロイを完了でき、ゼロから始める必要はありません。
