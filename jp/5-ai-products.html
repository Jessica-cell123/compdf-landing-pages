产品 1

ComPDF AI
智能文档处理引擎

ComPDF AI は中核となるインテリジェント文書処理エンジンであり、複雑な PDF レイアウト、表、段落構造を自動解析し、キーフィールドデータを高精度に抽出します。デジタル PDF でもスキャン文書でも、RAG、BI、エンタープライズシステムに直接利用可能な構造化データを出力できます。
  • 📤智能文档抽取 — 从发票、合同、报表中自动提取金额、日期、供应商等关键字段
  • 📄智能文書解析— レイアウト、テーブル、段落階層を深層解析し、Markdown / JSON を出力
  • 🌐多言語サポート — 覆盖中、英、日、韩等 50+ 语言文档
  • 🔗RAG 就绪— 出力は LangChain、LlamaIndex、Dify などのフレームワークで直接利用可能
  • 🛡️フレキシブルデプロイ— クラウド API 或プライベートデプロイ，满足データコンプライアンス要求
🤖

产品 2

AI アシスタント
自然言語で AI に文書処理を指示

AI アシスタントが Web Demo に組み込まれており、自然言語で要件を伝えるだけです — 「すべての金額をハイライト」「ID番号を黒塗り」「契約書の当事者を抽出」— AI アシスタントが意図を理解し自動実行。操作トレーニングは一切不要です。
  • 💬リアルタイム QA — 针对文档内容提问，AI 即时回答并标注来源
  • 📝一括注釈 — 一句话批量添加高亮、下划线、删除线等标注
  • ✏️コンテンツ編集— "タイトルを赤色に変更"、"第 3 段落を削除"，AI 准确执行
  • 🔒機密マーク — 自动识别敏感信息并进行涂黑脱敏处理
  • 🌐すぐに使える — 集成在 Web Demo 中，零配置即可体验
💬

対話型操作

用户：把第 3 页所有金额数字高亮标注
AI アシスタント：已完成，共标注 12 处金额数字 ✓
用户：将文档中所有身份证号做機密情報処理
AI アシスタント：已识别 5 处身份证号并完成涂黑 ✓
产品 3

AI Skills
30+ PDF 技能，AI Agent プラグアンドプレイ

AI Skills は ComPDF の全 30 以上の PDF 処理機能を AI Agent が直接呼び出せるスキルパッケージにカプセル化します。編集、変換、抽出、生成 — あなたの AI アシスタントが PDF を操作できるようになりました。Claude、GPT などの Agent が Skills を通じて関数呼び出しのように文書を処理します。
  • ✏️編集系 Skills— テキスト編集、注释添加、合并分割、ページ管理
  • 🔄変換系 Skills— PDF ⇄ Word / Excel / PPT / HTML / 画像
  • 📤抽出系 Skills— テキスト抽出、テーブル認識、图片提取、KVP 字段提取
  • 📄生成系 Skills — 模板填充、报告生成、水印添加、批量输出
  • 🧩Agent Ready— Claude、GPT、OpenClaw などの主要 AI Agent に対応

产品 4

MCP Server
AI が PDF 機能を直接呼び出し

MCP Server は Model Context Protocol 標準プロトコルに基づき、ComPDF のドキュメント処理機能を MCP 対応の AI アプリケーションに開放します。Claude Desktop、Cursor、Windsurf などのツールが MCP Server を設定するだけで、AI が直接 PDF の読み取り、編集、変換をコード統合なしで実行できます。
  • 🔌標準プロトコル — 基于 MCP 标准，一次接入随处可用
  • 🤖AI ネイティブ — 让 Claude、GPT 等模型直接读写 PDF 文件
  • 🔗マルチツールサポート— Claude Desktop、Cursor、Windsurf などに対応
  • ⚙️インテリジェントルーティング — AI 根据任务自动选择合适的 PDF 处理方法
  • 🛡️セキュリティ管理可能 — 支持认证鉴权、用量控制与数据隔离
🔌

MCP プロトコル設定

{
  "mcpServers": {
    "compdf": {
      "url": "mcp.compdf.com",
      "capabilities": [
        "document_parse",
        "document_extract",
        "ocr"
      ]
    }
  }
}
