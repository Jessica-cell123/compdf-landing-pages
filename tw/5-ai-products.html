產品 1

ComPDF AI
智能文檔處理引擎

ComPDF AI 是核心的智能文檔處理引擎，自動解析複雜 PDF 版面、表格和段落結構，精準提取關鍵字段數據。無論是數字 PDF 還是掃描件，都能輸出可直接用於 RAG、BI 和企業系統的結構化數據。
  • 📤智能文檔抽取 — 從發票、合同、報表中自動提取金額、日期、供應商等關鍵字段
  • 📄智能文檔解析 — 深度解析版面、表格、段落層級，輸出 Markdown / JSON
  • 🌐多語言支持 — 覆蓋中、英、日、韓等 50+ 語言文檔
  • 🔗RAG 就緒 — 輸出可直接被 LangChain、LlamaIndex、Dify 等框架消費
  • 🛡️靈活部署 — 雲端 API 或私有化部署，滿足數據合規要求

產品 2

AI 助手
用自然語言指揮 AI 處理文檔

AI 助手嵌入 Web Demo 中，你只需要用自然語言說出需求 — "高亮所有金額"、"把身份證號塗黑"、"提取合同中的甲方乙方" — AI 助手理解你的意圖並自動執行，無需任何操作培訓。
  • 💬實時問答 — 針對文檔內容提問，AI 即時回答並標註來源
  • 📝批量註釋 — 一句話批量添加高亮、下劃線、刪除線等標註
  • ✏️內容編輯 — "把標題改成紅色"、"刪除第三段"，AI 準確執行
  • 🔒密文標記 — 自動識別敏感信息並進行塗黑脫敏處理
  • 🌐即開即用 — 集成在 Web Demo 中，零配置即可體驗

產品 4

MCP Server
讓 AI 直接調用 PDF 能力

MCP Server 基於 Model Context Protocol 標準協議，將 ComPDF 的文檔處理能力開放給任何兼容 MCP 的 AI 應用。Claude Desktop、Cursor、Windsurf 等工具通過配置 MCP Server，即可讓 AI 直接讀取、編輯和轉換 PDF，無需編碼集成。
  • 🔌標準協議 — 基於 MCP 標準，一次接入隨處可用
  • 🤖AI 原生 — 讓 Claude、GPT 等模型直接讀寫 PDF 文件
  • 🔗多工具支持 — 兼容 Claude Desktop、Cursor、Windsurf 等
  • ⚙️智能路由 — AI 根據任務自動選擇合適的 PDF 處理方法
  • 🛡️安全可控 — 支持認證鑑權、用量控制與數據隔離
