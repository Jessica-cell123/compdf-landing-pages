AI 助理已整合至 Web 示範。使用者只需透過自然語言描述需求，例如：「突顯所有金額」、「隱藏身分證字號」、「刪除第三段內容」，AI 即可自動理解意圖並執行操作，無需學習複雜工具。
  • 💬表單填寫：自動識別表單欄位，並依要求完成互動式表單填寫。
  • 📝批量註釋：一句指令即可批量完成高亮、底線、刪除線等註釋操作。
  • ✏️內容編輯：支援「將標題改為紅色」、「刪除第三段」等自然語言編輯指令。
  • 🔒敏感資訊去識別化：自動識別敏感資訊並完成去識別化標記處理。
  • 🌐開箱即用：無需配置，直接在 Web 演示中體驗 AI 文件處理能力。

MCP Server

  • 🔌標準協議支援：基於 MCP 標準協議，一次接入，多端可用。
  • 🤖AI 原生整合：支援 Claude、GPT 等模型直接讀寫 PDF 檔案。
  • 🔗多工具兼容：兼容 Claude Desktop 等主流 MCP 工具生態。
  • ⚙️智能任務路由：AI 可根據任務自動選擇最適合的 PDF 處理方式。
  • 🛡️安全可控：支援權限認證、呼叫控制與資料隔離。
