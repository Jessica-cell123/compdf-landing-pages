  • 保留字體、字號、顏色等格式信息
  • 精準還原標題層級與段落關係
  • 支持 PDF 內嵌書籤與目錄結構

AI 驅動的版面分析

基於深度學習的版面檢測模型，可識別 10+ 種版面元素（標題、正文、表格、圖片、頁眉頁腳、腳註等），正確劃分文檔的邏輯閱讀順序。

  • 多欄、圖文混排自動分區
  • 標題與正文的層級自動關聯
  • 頁眉頁腳、水印自動過濾
  • 跨頁段落與表格自動拼接

複雜表格結構提取

採用專項表格檢測與單元格識別模型，準確還原合併單元格、嵌套表格、無線框表格的行列關係，輸出結構化表格數據。

  • 合併單元格精準還原行列映射
  • 無線框/虛線框表格識別
  • 跨頁表格自動拼接與續表識別
  • 表格數據輸出為 HTML / Markdown / JSON
🔤

掃描件 OCR + 版面還原

對圖片型 PDF 和掃描件，先進行高精度 OCR 文字識別，再通過版面分析還原文檔結構，使其達到與數字 PDF 相同的解析質量。

  • 支持 50+ 語種 OCR 識別
  • 傾斜校正與圖像增強預處理
  • OCR 結果自動套用版面結構
  • 手寫體與印刷體混合識別
