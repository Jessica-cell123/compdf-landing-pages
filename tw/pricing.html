FAQ

常見問題

ComPDF SDK 如何定價？▼
SDK 按年授權，價格根據所選平臺（Web / 移動端 / 桌面端 / 服務端）和功能組合確定，最低 $1,300/年起。不限文檔處理量和不限用戶數。
SDK 支持哪些平臺？▼
支持 Web（JavaScript）、iOS、Android、Flutter、React Native、Windows、macOS、Java、.NET 共 9 大平臺。
如何獲取 SDK 試用？▼
註冊 ComPDF 會員即可申請 30 天全功能免費試用 License，無需信用卡。試用期間可體驗所有功能和平臺。
Cloud API 的文檔量如何計算？▼
每次 API 調用處理一頁文檔計為一份。免費層每月 200 份，Growth 層 5,000 份，Pro 層 10,000 份。超過部分可購買附加包或升級方案。
API 支持哪些功能？▼
支持 PDF 轉換（Office/圖片/HTML）、PDF 編輯（合併/拆分/旋轉）、OCR 識別、水印添加、壓縮、AI 文檔解析與抽取等。
是否支持私有化部署？▼
支持。SDK 支持私有化部署，API 也提供 Self-hosted 方案。數據部署在自有服務器，不出企業內網。
是否提供企業折扣？▼
提供。年採購量大的客戶可享受批量折扣，支持 OEM 授權模式。請聯繫銷售團隊獲取定製報價。
SDK 和 API 可以同時使用嗎？▼
可以。許多客戶同時使用 SDK（用於客戶端查看/編輯）和 API（用於服務端批量處理），兩者互補。
